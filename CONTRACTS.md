# Cross-boundary contracts

Code comments in this repo reference "dashie-voice-integration CONTRACTS.md" —
the registry of every contract shared between the add-on (this repo), the
[Dashie Voice integration](https://github.com/jwlerch78/dashie-voice-integration),
and satellite devices (bridge paths, auth, turn shapes, the console
core ↔ Dashie delta seam, …).

**The registry lives in the integration repo:**
[dashie-voice-integration/CONTRACTS.md](https://github.com/jwlerch78/dashie-voice-integration/blob/main/CONTRACTS.md)

(One copy, linked from both sides, so it can't drift. The rule it encodes,
inherited from hard-won postmortems: before hand-mirroring anything across a
boundary, add a row there — and prefer sharing one copy over mirroring at all.)
